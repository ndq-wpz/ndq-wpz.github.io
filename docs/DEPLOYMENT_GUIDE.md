# Deployment (not yet approved)
Review the standalone HTML and review projects-first layout; career information has been confirmed by the user. The `dist/` directory is a static build; upload its contents (not the directory itself) to the root of your GitHub Pages repository, keeping `assets/`, `site.css`, `interactions.js`, and `index.html` together. `review.html` is optional and not needed for the public site. Add an empty `.nojekyll` file. In the GitHub repository, choose Settings > Pages > Deploy from a branch > main > /(root). Verify the resulting URL, chart interactions, CV download, mobile navigation and privacy. Before public release, decide whether to remove `noindex,nofollow` from `src/page.mjs` and rebuild, and confirm the CV and its contact details are appropriate to publish. Do not overwrite an existing repository or publish until authorized.
